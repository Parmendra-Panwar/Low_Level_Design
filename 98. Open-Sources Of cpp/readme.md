# here is the list of project that can help to learn cpp deeply

Here is a curated table of 15 open-source C++ projects spanning operating systems, databases, libraries, and tools, organized roughly from easier to more challenging, covering a broad spectrum of real-world applications:

| Project Name         | Category           | Description                                                    | Difficulty Level  | GitHub / Link                              |
|----------------------|--------------------|----------------------------------------------------------------|-------------------|--------------------------------------------|
| **Catch2**           | Testing Framework  | Header-only C++ testing framework                              | Easy              | https://github.com/catchorg/Catch2         |
| **fmtlib (fmt)**     | Formatting Library | Modern formatting library (alternative to iostream formatting) | Easy              | https://github.com/fmtlib/fmt               |
| **spdlog**           | Logging Library    | Fast, header-only logging library                              | Easy-Medium       | https://github.com/gabime/spdlog            |
| **JSON for Modern C++** | JSON Parsing     | JSON serialization/deserialization library                     | Medium            | https://github.com/nlohmann/json            |
| **SQLite**           | Database           | Small, embedded SQL database engine                            | Medium            | https://www.sqlite.org/index.html           |
| **LevelDB**          | Database           | Fast key-value storage library                                 | Medium-Hard       | https://github.com/google/leveldb           |
| **Bitcoin Core**     | Blockchain/Finance | Core software for bitcoin cryptocurrency                        | Hard              | https://github.com/bitcoin/bitcoin          |
| **libuv**            | Asynchronous I/O   | Multi-platform asynchronous I/O                               | Hard              | https://github.com/libuv/libuv               |
| **Electron (parts in C++)** | Application Framework | Cross-platform desktop apps, C++ in Chromium backbone          | Hard              | https://github.com/electron/electron        |
| **TensorFlow Lite (C++ core)** | Machine Learning | Lightweight ML inference engine                               | Hard              | https://github.com/tensorflow/tensorflow    |
| **OpenCV**           | Computer Vision    | Computer vision and machine learning library                   | Hard              | https://github.com/opencv/opencv             |
| **Apache Arrow (C++ library)** | Data Processing | Columnar in-memory analytics platform                          | Hard              | https://github.com/apache/arrow              |
| **Kubernetes (client libraries in C++)** | Cloud/Containers | Interaction with Kubernetes API                                | Very Hard         | https://github.com/kubernetes-client/cpp    |
| **Qt Framework**     | UI Framework       | Cross-platform application and UI framework                   | Very Hard         | https://github.com/qt/qtbase                 |
| **Linux Kernel (Modules in C++)** | Operating System  | Core of Linux OS (mostly C, some C++ modules possible)          | Very Hard         | https://github.com/torvalds/linux            |

### Notes:
- Difficulty grading is relative—easy projects are suitable for beginners or early intermediate coders; very hard projects require deep domain and system-level knowledge.
- Many complex projects like Bitcoin Core, OpenCV, and Qt are exemplary for studying large-scale modular C++ software.
- Some projects like SQLite and LevelDB focus on efficient data structures and algorithms in C++.
- Libraries like Catch2, fmt, spdlog are more approachable and useful for everyday C++ programming improvements.
- Projects cover domains such as systems programming, databases, finance, graphics, machine learning, and cloud computing, giving you diverse exposure.

This list can guide you through progressively more challenging C++ codebases to learn practical skills and real-world C++ usage. If you want, detailed guidance on how to explore or contribute to any of these projects can be provided!

Here are some small and lightweight open-source projects specifically written in C++ focused on:

### Small ROS (Robot Operating System) Projects:
| Project Name           | Description                                             | Link                                 |
|------------------------|---------------------------------------------------------|-------------------------------------|
| **roscpp_tutorials**    | Beginner ROS tutorials in C++ covering fundamentals      | https://github.com/ros/ros_tutorials/tree/noetic/roscpp_tutorials |
| **turtlesim**           | Simple ROS simulator for learning ROS basics using C++   | https://github.com/ros/ros_tutorials/tree/noetic/turtlesim |
| **rclcpp (ROS2 client)** | Small client library for writing ROS2 nodes in C++       | https://github.com/ros2/rclcpp       |
| **ros_control**         | Lightweight C++ package to control robot hardware        | https://github.com/ros-controls/ros_control |

### Small Operating System Projects in C++:
| Project Name           | Description                                             | Link                                 |
|------------------------|---------------------------------------------------------|-------------------------------------|
| **IncludeOS**           | Minimal C++ unikernel OS for cloud and container usage  | https://github.com/includeos/includeos |
| **MikeOS**              | Simple hobby OS with some C++ support                    | http://mikeos.sourceforge.net/      |
| **Cosmos**              | C# and C++ based small OS for learning OS concepts      | https://github.com/CosmosOS/Cosmos  |
| **SerenityOS**          | Modern small Unix-like OS with C++ focus, growing rapidly| https://github.com/SerenityOS/serenity |

***

These projects are great starting points:
- ROS projects cover robotics middleware with real C++ node examples.
- Small OS projects like IncludeOS focus on minimalist OS design leveraging C++ features.
- Turtlesim is excellent for hands-on ROS practice in C++.
- SerenityOS is a community-driven OS focused on cleaner design with modern C++.

If you want recommendations on how to start contributing or learning from any of these, just ask!
